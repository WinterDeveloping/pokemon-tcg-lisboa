Se preferires colar à mão

  1. iPhone: Definições → Apps → Calendário → Contas → Adicionar conta → Outra → Adicionar calendário subscrito → colar o link.
  2. Google Calendar (no computador): "Outros calendários" → + → A partir do URL → colar o link.

O Google actualiza a cada 12–24 h e pode demorar até um dia a mostrar tudo pela primeira vez. No iPhone podes escolher a frequência nas definições da subscrição.
